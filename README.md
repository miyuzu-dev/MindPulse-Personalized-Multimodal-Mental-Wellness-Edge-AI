# MindPulse-Personalized-Multimodal-Mental-Wellness-Edge-AI
MindPulse là hệ thống Edge AI hỗ trợ theo dõi sức khỏe tinh thần cá nhân hóa, kết hợp tín hiệu giọng nói và PPG, ML/DL đa phương thức, học baseline cá nhân, TinyML và RAG để phát hiện sự thay đổi trạng thái và đề xuất các micro-intervention phù hợp.
